# Tự động đẩy code

- Khi hoàn thành một tác vụ lập trình hoặc thay đổi source code nào đó theo yêu cầu của người dùng, sau khi việc thay đổi đã được xác nhận hoặc tác vụ kết thúc, bạn phải **TỰ ĐỘNG** thực hiện lệnh `git add`, `git commit` và `git push` để đẩy code lên kho chứa (git/Cloudflare).
- Không cần người dùng phải nhắc nhở câu "đẩy code lên git". Hãy luôn chủ động chạy terminal command để commit và push khi code đã ổn định.
